# Candidate Promotion Safety

Promotion from staging to production is intentionally conservative.

Before a candidate can become a production place:

- review state must be `APPROVED`,
- reviewed coordinates are required,
- current certification evidence is required for certified labels,
- the production slug must be unused,
- an active place of the same type within 150 metres blocks promotion as a
  potential duplicate.

The duplicate guard is a safety gate, not a claim that two nearby businesses
are always the same. If two legitimate places are within 150 metres, review
their identity first and resolve the conflict deliberately rather than
overwriting an existing place.

Promotion never updates an existing row merely because a slug collides.
